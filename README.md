# Совет консультантов — Career Council

Система помогает обдумать смену карьеры: один исходный вопрос проходит через пять независимых консультантов, общий проект решения и оценки всех участников. Пользователь получает план, альтернативы, риски, условия и сохранившиеся разногласия. Итоговое решение принимает человек.

Фиксированные персоны: **Peter Thiel, Warren Buffett, Robert Reich, Nassim Nicholas Taleb и Marcus Aurelius**. Это симуляции их подходов, а не высказывания реальных людей. Исходный вопрос в [main.py](council/main.py) сохранён без изменения.

## Текущее состояние

Все пять персон сохранили возражения к переходу без необходимых данных; отчёт содержит полезный условный план, а не единогласное одобрение смены карьеры.

## Запуск из корня проекта

PowerShell, Python и зависимости из зафиксированного списка:

```powershell
py -m venv .venv-consensus
.\.venv-consensus\Scripts\python.exe -m pip install -r council/requirements.lock.txt
Copy-Item council/.env.example council/.env
```

В локальном `council/.env` укажите `LLM_PROVIDER`, точный `LLM_MODEL` и ключ выбранного провайдера (`AITUNNEL_API_KEY` или `OPENAI_API_KEY`). Если окружение и файл уже настроены, повторять подготовку не требуется. Секретный `.env`, виртуальное окружение и кэш исключены из Git.

Команда, использованная для завершённого реального отчёта:

```powershell
.\.venv-consensus\Scripts\python.exe -X utf8 -m council.main --mode model --reasoning-effort none --aitunnel-test-mode --max-rounds 1
```

Проверенный профиль: AI Tunnel, `gpt-6-luna-pro`, reasoning `none`. `--aitunnel-test-mode` применим только к AI Tunnel: запрашивается 2 000 токенов, действует отдельный согласованный потолок приёма 8 000. Это условный тестовый профиль. Для строгого режима уберите этот флаг; работа с прямым OpenAI в данном живом кейсе не проверялась.

`--max-rounds` принимает 1–3, по умолчанию 3. Один раунд завершает обсуждение после пяти валидных оценок даже при разногласиях. `consensus` и `no_consensus` дают exit 0; ошибки, отмена и незавершённость имеют отдельные статусы и не выдаются за содержательное разногласие. Без `--mode model` CLI использует сценарный режим.

Проверка реализации без платных обращений:

```powershell
.\.venv-consensus\Scripts\python.exe -m pytest council/tests -q
.\.venv-consensus\Scripts\python.exe -m council.main --mode scripted --scenario revise
.\.venv-consensus\Scripts\python.exe -m council.main --mode scripted --scenario disagree
```

Сценарные ответы проверяют протокол, а не качество модели. Первый запуск поиска может загрузить локальную embedding-модель.

## Как устроено обсуждение

LangGraph задаёт маршрут: отбор заметок → выбор read-only инструментов → пять независимых позиций → общий проект → пять оценок → проверка согласия → остановка или пересмотр в пределах бюджета.

Исходные цитаты, происхождение данных, версии решения и владельцы возражений проверяются программой. Модель выбирает аргументы и оценивает их смысл; точное совпадение цитаты само по себе не доказывает поддержку вывода. Отчёты и trace сохраняются в `council/output/<run_id>/`.

Исходники `council` включены в основной репозиторий как обычные файлы: для получения продукта после клонирования не нужен отдельный submodule.

## Следующие задачи

1. Усилить различимость голоса и проверить её на нескольких вопросах, сохраняя реальные различия принципов, а не назначая формального «контраргументатора».
2. Разделять исходные факты и предположения точнее. В последнем кейсе один аргумент о возможной начальной зарплате не подтверждён выбранной финансовой цитатой, а один итоговый claim смешивает факт темпа учёбы и предположение о пользе проекта. Условия и независимые квалификации сохранены.
3. Подтвердить живой пересмотр и обработку возражений в следующих раундах в пределах согласованного контекста; не считать сценарные проверки доказательством живого пути.
4. Оценить устойчивость на разных досье, качество поиска, стоимость и задержки. Текущий успешный кейс не является production-гарантией.

Новые платные запуски требуют отдельного разрешения. Текущий порученный демонстрационный результат завершён; перечисленные улучшения остаются будущими задачами.
