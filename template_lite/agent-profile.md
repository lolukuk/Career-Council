# <Название роли>

Это reusable template, а не готовый project agent. Только после появления реальной feature и достаточного контекста замените все `<...>`; `name` — доменное имя из строчных латинских букв и дефисов, например `credit-agent-architect`, `fraud-agent-evaluator`, `support-agent-runtime-engineer` (примеры, не выбранные задачи).
